# ワイさんすう テスト計画書

## 1. テスト対象

ワイさんすう v1.0（たし算ドリルWebアプリ）

## 2. テスト環境

- ブラウザ: Chrome（最新版）
- 画面サイズ: 375×667（iPhone SE相当）および 1280×720（デスクトップ）
- URL: http://localhost:3000

## 3. テストケース

### TC-01: ホーム画面の表示

- [ ] アプリタイトル「🔢 ワイさんすう」が表示される
- [ ] 「たし算」カードが活性状態で表示される
- [ ] 「ひき算」「かけ算」「わり算」カードがグレーアウト＋「Coming Soon」表示
- [ ] 「たし算」カードをクリックするとレベル選択画面に遷移する
- [ ] グレーアウトカードをクリックしても遷移しない
- [ ] 「📋 がくしゅうの きろく」リンクが表示される

### TC-02: ユーザー管理

- [ ] 初回アクセス時にユーザー作成UIが表示される
- [ ] ユーザー名入力とアバター選択（絵文字10種）ができる
- [ ] ユーザーを作成すると表示名が更新される
- [ ] 2人目のユーザーを作成して切り替えできる
- [ ] ユーザー切替後もページが正常に動作する

### TC-03: レベル選択画面

- [ ] レベル1〜11のカードが表示される
- [ ] 各カードにレベル番号、○タイム、◎タイム、問題数が表示される
- [ ] 戻るボタン（←）でホームに遷移する
- [ ] レベルカードをタップするとドリル画面に遷移する

### TC-04: ドリル実行 — レベル1（タイプA: 直接回答）

- [ ] カウントダウン「3→2→1→スタート！」が表示される
- [ ] カウントダウン後に問題が表示される
- [ ] **画面にタイマーは表示されない**
- [ ] 問題説明文が問題の上に表示される
- [ ] 問題「A + B = [ ]」形式で表示される（1桁+1桁）
- [ ] テンキー（0〜9、⌫、→）が表示される
- [ ] 数字入力で回答欄に値が表示される
- [ ] ⌫で末尾1文字削除される
- [ ] →で回答送信 → **正誤フィードバックなしで即座に次の問題へ**
- [ ] 不正解でも次の問題に進む
- [ ] 進捗バーが更新される（例: 2/36）
- [ ] 36問全て回答後に結果画面に遷移する
- [ ] 入力は最大4桁に制限される

### TC-05: ドリル実行 — レベル3（タイプB: 部分回答）

- [ ] 例題が表示される（「（れい）67 + 28 ⇒ 15 … 7+8=15」）
- [ ] 問題「A + B ⇒ [ ]」形式で表示される
- [ ] 1の位同士の和が正答として判定される（例: 7+8=15）

### TC-06: ドリル実行 — レベル5（タイプC: 分解回答）

- [ ] 例題が表示される（「（れい）67 + 22 = 80 + 9 = 89」）
- [ ] 問題「A + B = [ ] + [ ] = [ ]」形式で表示される
- [ ] 回答欄が3つ表示される
- [ ] アクティブステップがハイライトされる
- [ ] ステップ1送信 → ステップ2にフォーカス移動
- [ ] ステップ2送信 → ステップ3にフォーカス移動
- [ ] ステップ3送信 → 次の問題
- [ ] Escapeキーで現在ステップの入力クリア

### TC-07: 結果画面

- [ ] 全問正解＋◎タイム以内 → ◎合格表示
- [ ] 全問正解＋○タイム以内 → ○合格表示
- [ ] 1問でも不正解 → 不合格表示
- [ ] タイムオーバー → 不合格表示
- [ ] 経過時間が表示される
- [ ] 正答数/全問数が表示される
- [ ] 全問正解時: 「🎉 ぜんもん せいかい！」が表示される
- [ ] 間違いあり時: 間違えた問題の一覧と正解が表示される
- [ ] 「もういちど」ボタンで同レベル再挑戦できる
- [ ] 「レベルせんたく」ボタンでレベル選択画面に戻る

### TC-08: データ永続化

- [ ] ドリル完了後にクリア履歴が保存される
- [ ] レベル選択画面にベストスコアの判定バッジが表示される
- [ ] ブラウザリロード後も履歴が保持される
- [ ] ユーザー別に履歴が分離されている

### TC-09: 学習の記録

- [ ] /history にアクセスで学習記録画面が表示される

- [ ] グラフに○タイム・◎タイムの基準線が表示される
- [ ] 履歴リストに判定バッジ（◎/○/△）・タイム・日時が表示される

### TC-10: 効果音

- [ ] カウントダウンで音が鳴る
- [ ] 結果画面で判定音が鳴る

### TC-11: レスポンシブ対応

- [ ] 375px幅でレイアウト崩れなし
